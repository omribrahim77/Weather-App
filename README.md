# Weather App 🌤️

A modern and responsive web application designed to display real-time weather information, forecasts, and atmospheric conditions with a clean and elegant user interface.

[Live Demo](https://omribrahim77.github.io/Weather-App/)

---

## ✨ Features (المميزات)

- **Current Weather Display:** View current temperature, weather conditions (e.g., Sunny, Rainy), and location details.
- **Detailed Metrics:** Monitor precipitation percentages, humidity levels, and wind speeds.
- **Multi-day Forecast:** Check upcoming weather conditions and temperatures for the next few days.
- **Responsive Design:** Optimized for seamless viewing across desktop, tablet, and mobile devices.

---

## 🚀 Built With (تقنيات البناء)

- **HTML5** & **CSS3** (or modern CSS frameworks/preprocessors)
- **JavaScript (ES6+)** for dynamic data rendering and DOM manipulation
- **Weather API** for fetching real-time meteorological data
